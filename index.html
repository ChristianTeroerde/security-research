02 / PuTTYFixed · Public credit

SSH tooling · Memory safety

Missing Argon2 parameter validation in private-key files

A malicious PPK file could cause a buffer overflow in password hashing. PuTTY added validation of the Argon2 parameters read from the key file.

Vendor classification
Security vulnerability
Fixed in
PuTTY 0.85
“Thanks to Christian Terörde for discovering this bug.”— PuTTY maintainers

The vendor describes a narrow attack scenario requiring an externally supplied private-key file. A crash is the expected impact; controlled code execution is not established.

04 / BizFiloFixed · Public credit

Shopify tooling · Access control

Shopify MCP server exposed store data to unauthenticated network clients

The server listened on all interfaces and accepted MCP tool calls without caller authentication. With an operator's Shopify token configured, a reachable client could invoke tools for customer and order data.

Fixed in
1.1.1
Published
6 October 2026

The maintainer's public security note credits 0xwaidwerk for the private report. The local reproduction used a dummy Shopify token.
